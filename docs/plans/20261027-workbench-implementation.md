# 每日采价工作台：本地实现与验收记录

本地预览：<http://localhost:8001/?view=raw>。Vite 绑定 `0.0.0.0:8001`，后端使用独立的 `8788` 端口，保留原有 `8787` 服务。当前改造尚未发布到云端。

## 数据与账号

- 本地隔离目录：`data/preview-20261027/`，来自云端 SQLite 在线一致性备份和工作簿副本。
- 原始库 `raw-editor-draft.sqlite` 保留 286 个原有 SKU、49 个日期；新代码对它只读迁移。
- 在线编辑、新 SKU、每日报价、核验和日志存入独立的 `price-workbench.sqlite`。
- `published-price-draft.sqlite` 是生效价格的兼容投影，可以重新生成；它不是第二个业务写入口。
- 首批逐行比对后导入 394 个 SKU：复用 211 个、新增 183 个，总计 469 个。135 项自动校验生效，143 项券价关系异常、116 项未匹配待核验；75 个来源外旧 SKU 保留。
- 读取云端已派生的旧机 S 等级 BI 快照到本地，仅用于预览分析；没有写入云端业务数据。
- 初始账号为 `admin`、`reviewer1`、`reviewer2`，随机密码保存在 `data/preview-20261027/workbench-initial-accounts.json`，权限为 0600，文件不纳入 Git。可在账号管理改姓名和账号、重置密码，登录后可以修改自己的密码。
- 固定一个管理员、两个核验席位；所有新建账号只能只读。匿名访问也是只读。所有编辑请求都在后端鉴权，旧整表写入口关闭；旧 BI 确认入口仅允许管理员更新指定 PPV 的 BI 字段。

## 已实现

1. 每日采价、型号维度、核验队列、任务与日志、管理员账号管理。
2. 按日展示型号与存储，挂牌/券额按单元格保存，国补后服务端按用户公式计算并四舍五入到分。
3. 字段级乐观版本控制；不同字段可合并，同字段冲突不覆盖。批量粘贴先预览、再原子保存；任一单元格冲突则整批回滚。
4. 原始响应、人工工作值、生效价格版本分开保存。重复导入幂等；新查询不能覆盖当天人工修改或确认。
5. 新接口结果与已确认值不同会进入待比较，可采用到工作记录后重新确认，也可说明原因保留人工值。
6. 核验领取和到期、商品/搜索链接、证据链接与结论、在售/无货/停售/未上市状态。管理员可撤销或恢复生效版本，保留完整历史。
7. 14 家指定店铺与型号/容量/特殊版匹配；券额、actualPrice、券期/门槛、价格跳变及来源变化校验；错误响应不当作“未匹配”。
8. 持久化采价任务和 SKU 队列、最多 4 个并发、失败退避重试、进程租约、崩溃恢复、北京时间 10:00 日程槽位防重。只能把当前 API 报价写到当天，不能伪造历史/未来报价。
9. SQLite 审计记录、原始响应脱敏、请求 ID、失败尝试日志和可追溯发布；SSE 同步保存与采集进度。
10. 生效数据投影及数仓刷新 outbox，失败保留并重试；数仓按批次去抖。新采价日期缺失不沿用昨日价、不记零元，新增 SKU 即使没价格也保留在数仓维度。
11. 概览、风险、专家数仓和只读 MCP 接入生效数据；原有历史口径保留。导出当天表格保留国补计算公式，空/非法价格不出计算值。

## 启动

分别在两个终端运行：

```bash
npm run preview:api
npm run dev
```

`preview:api` 使用隔离数据目录，明确关闭价格采集和微博销量自动日程。真实手动采集仍可使用；界面提供整日或单个 SKU 的入口。日程逻辑已经实现，本地不会到点触发全量请求。

买手参数只在服务端：环境变量 `MAISHOU_INVITE_CODE`、`MAISHOU_OPENID`、`MAISHOU_HEADERS_JSON`，或私密文件 `data/maishou-provider.json`。本地预览配置在隔离目录内，不上传到前端，也不纳入 Git。

## 首批导入

脚本 `scripts/import-price-batch.mjs` 针对已确定的 1027 工作簿：必须传 `--source`、`--evidence`、`--data-dir`、`--date`；默认仅预检，传 `--apply` 才会写入指定目录。它对 Excel 型号、存储、三个金额字段逐行比对，附带相邻 `details.json` 中的原始详情，按文件 SHA256 防止重复导入。

云端发布时应基于当时最新的生产原始库做迁移，再运行同一导入流程；**不能用本地预览数据库覆盖云端数据库**。先备份、关闭旧整表写入、迁移与导入、验证业务数字、配置账号及 API，最后再打开每日 10:00 日程。

## 验收证据

- 自动测试覆盖公式边界、SKU 去重、原始库不变、幂等导入、多人字段冲突、批量回滚、领取、权限、人工覆盖保护、新报价采用、撤销恢复、BI 兼容、采价日期、持久化任务恢复、outbox 重试及 Excel 导出公式。
- 浏览器验证了只读与管理员状态、价格保存与公式重算、旧生效值保护、人工确认、来源历史、型号维度和固定角色账号页。
- 真实接口单 SKU 验证取得“小米 18 Pro 12GB+256GB”的指定自营店价格及购买链接；另外通过本地任务完成一个 REDMI SKU 的搜索/详情链路，验证人工编辑不会被反写。
- 浏览器功能验收涉及的临时编辑与确认已移动到 `data/preview-20261027/.archive/browser-acceptance-*`，没有删除。当前预览重新导入干净数据，不把功能测试结论冒充真实价格核验。

上线前仍需由管理员把两个核验席位改成实际人员姓名并分发密码，再在生产环境完成一次受控采集验收与日程启用。本地预览不会替代工作室对异常优惠券和商品在售状态的人工确认。

# Mate 90 漏匹配与日志复查

2026-10-27，按用户反馈复查。修复和采价均在 `8001` 本地预览；未修改云端生产数据。

## 发现

- 原页面部分空白来自首次导入的“未匹配”，没有执行新工作台的实时重查，不能据此判断目前搜索不到。
- 旧匹配器去掉空格后，把型号紧接的 `12GB+256GB` 当作额外型号后缀，导致部分同规格标题被拒绝。
- 原导入只记批次与自动生效，漏了逐 SKU 的未匹配明细。日志只展示最近 200 条且缺少型号列，也不利于检索。

## 修复

- 区分型号后缀与合法 RAM+ROM，保留 Pro/Pro Max、特别版等边界；特殊版标记允许出现在标题前部。
- 补充带/不带空格、去品牌、紧凑型号、容量简写、系列和 2–3 页检索兜底；候选详情不合格时继续其他检索。
- 放宽检索词后仍严格检查品牌对应的指定自营店、型号、容量与特殊版本；多规格混合标题不直接采用。
- 记录每一步查询词、页码、返回数量、店铺/规格排除、详情结论。缓存复用会明确标记；接口失败与未匹配分开。
- 补录历史导入的逐 SKU 日志，标注“导入未匹配，未执行新搜索”，不伪造查询事实或过去的执行时间。
- 日志支持按型号/存储搜索、业务日期筛选和全部历史分页；增加型号列及可读结果。日志关联字段建立索引。
- 任务进度区分已处理、匹配、未匹配、请求失败，不能把“14 项处理成功”写成“14 项都匹配”。

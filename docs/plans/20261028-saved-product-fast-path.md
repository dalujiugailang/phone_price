# 上次商品优先直查（2026-10-28）

每个“型号＋存储版本”已成功匹配的商品 ID、商品链接、报价和原始接口证据均保存在 SQLite observations 中。本次无需新增或迁移历史数据：采价时读取该 SKU 截至采价日最近的成功商品，后续失败记录不会抹掉这一入口。

顺序：

1. 有历史成功商品时，使用保存的 goodsId 调用商品详情，并重新取得可打开的链接。
2. 每次重新取挂牌价、优惠券和接口到手价，不复用历史金额，也不拿旧金额填空。
3. 重新校验指定店铺、型号、运行内存、存储容量和版本。商品及价格校验通过，直接完成该 SKU，search 调用为零。
4. 旧 ID 过期、详情/链接不可用、价格缺失、规格/店铺变化或价券校验未通过时，自动按完整搜索计划兜底；若只是价格矛盾，会继续比较其他同规格候选。
5. 新匹配的商品随正常采价保存，后续采价自动使用最近成功记录。人工修改及确认保护逻辑保持生效。

日志新增“优先查询上次商品”和“上次商品校验”阶段，包含直接取得最新价格或回退搜索的原因。快速完成结果的 raw.summary.fastPath=true，searches=0。

接口中的 isOnline=0 在实测正常商品中普遍存在，因此不能单独解释为下架。以详情业务返回、商品与价格有效性判断是否需要回退；不凭无明确语义的状态码将商品判为停售。

验证：48 项测试通过，类型检查、构建和 diff 检查通过。覆盖持久化重启后复用、失败不抹掉历史成功入口、每次刷新价格、旧 ID 失效/规格变更/详情无价/店铺或链接异常的搜索回退。实际买手接口直查 REDMI K100 Pro Max 12GB+256GB 约 1.237 秒，1 次详情、0 次 search，取得挂牌 4299 元、券额 550 元（仅证明该次采价，不代表长期价格）。

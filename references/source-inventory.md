## 来源优先级

1. 当前应用实际使用的Excel或更新日期不早于Excel的原始数据草稿。
2. 市场趋势与新品周销SQLite中的已确认业务数据。
3. DailyPrice DuckDB中的S等级BI出货价。
4. 页面或Agent生成的分析结论不作为数仓事实来源。

## 已知缺口

- DailyPrice当前库只保留最新快照，2026-07-06之前的S等级历史尚未回填。
- 华为 nova 15 Pro普通版与昆仑玻璃版当前共用一个S等级PPV。数仓标记为映射冲突，
  在业务确认正确PPV前不将该BI价分配给任一SKU。
- 本地市场趋势和新品周销目前只到W21；刷新脚本会以当前SQLite内容为准，不臆造后续周数据。

## 验证

运行：

```bash
npm run warehouse:verify
```

校验内容包括四张事实表颗粒度唯一性、PPV映射状态、三张业务宽表可用性，以及
新机价格聚合结果与当前【概览】品牌、机型定位和型号系列逻辑的一致性。
